# TOUCH

نسخة أولية تجريبية لتطبيق TOUCH بواجهة عربية.

## محتويات النسخة
- شاشة رئيسية عربية.
- رصيد تجريبي.
- اختصارات لخدمات شحن الهاتف وببجي والإيداع والسحب والتحويل والبطاقات.
- سجل عمليات تجريبي.

**تنبيه:** لا توجد حالياً عمليات مالية حقيقية أو ربط بمزود دفع. لا تستخدم هذه النسخة لاستلام الأموال أو تنفيذ تحويلات.

## بناء APK
ارفع محتويات هذا المشروع إلى مستودع GitHub على الفرع `main`. سيبدأ GitHub Actions بناء APK تلقائياً. يمكن تنزيل الملف من:
Actions → Build TOUCH APK → Artifacts → TOUCH-APK.
